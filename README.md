# password-generator
Python ile geliştirilmiş şifre oluşturucu.

Program, kullanıcının belirlediği uzunlukta rastgele şifre oluşturur. Oluşturulan şifre harf, rakam ve özel karakterler içerir

## Özellikler
- Şifre uzunluğunu ve ne kadar şifre olacağını kullanıcı belirler
- Harf, rakam ve özel karakter içerir.

## Kullanılan Teknoloji

- Python 3

## Nasıl Çalıştırılır?

```bash
python password_generator.py
```
